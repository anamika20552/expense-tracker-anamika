# Expense Tracker

A responsive expense tracker built with HTML, CSS, and vanilla JavaScript. It lets users record income and expenses, update or remove entries, view totals, and filter transactions. Data is saved in the browser using LocalStorage.

## Features

- Add income and expense transactions
- Record amount, category, date, and description
- Edit and delete transactions
- View total income, total expenses, and current balance
- Filter by transaction type and search by category
- Persist data across page refreshes with LocalStorage
- Responsive layout for desktop and mobile
- Basic input validation and delete confirmation

## Technologies

- HTML5
- CSS3
- JavaScript 
- Browser LocalStorage

## Run locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

No package installation, backend, or database is required.

## Files

- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — transaction logic and LocalStorage
